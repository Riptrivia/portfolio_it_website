Practice prompts

Explore without guessing.

01

Identify the system

Inspect the kernel, architecture, available memory, storage layout, and mounted filesystems.

uname -a · free -h · lsblk
02

Read permissions

Create a test file, inspect its current mode, and compare symbolic permissions with the Lab calculator.

touch lab.txt · ls -l lab.txt
03

Inspect networking

Review interfaces, addresses, and the route table without changing the VM configuration.

ip address · ip route
